# Dribbble-уровень: слои визуального качества

Универсальная модель повышения визуального качества интерфейса. Не привязана к конкретному продукту или задаче.

Dribbble-уровень — это не одна библиотека, а **слои**. Вот полный набор, от базы до "вау-эффекта":

---

## Слой 1: База (фундамент)

Базовый стек покрывает около 40% визуального уровня:

- shadcn/ui, Radix, Tailwind 4, Motion, Tremor — это база.
- Без этого дальше нет смысла.

---

## Слой 2: Анимированные компоненты (недостающее)

**Magic UI** — обязателен. Именно он дает те самые "Dribbble-эффекты":

- Shimmer-бордеры, gradient-фоны.
- Marquee-ленты.
- Animated beam (идеально для визуализации потоков данных).
- Number ticker (для счетчиков и метрик).
- Dock-анимации.
- Meteors, particles, grid-pattern.

Это одно решение, которое поднимает визуал с "хорошо" до "замечательно".

---

## Слой 3: Типографика и шрифты

**Inter — переиспользован до смерти.** Каждый второй SaaS на нем.

Для Dribbble-уровня нужен более выразительный набор:

- **Заголовки:** `Geist` (от Vercel), `Satoshi` (от Fontshare) или `Cabinet Grotesk`.
- **Body:** `Inter` подойдет (он хорош для текста, просто не для заголовков).
- **Моноширинный:** `JetBrains Mono` — хороший выбор.

Минимальное изменение с максимальным эффектом — заменить заголовочный шрифт.

---

## Слой 4: Иконки

**Lucide** — функциональный, но скучный. Для премиум-визуала:

- **Phosphor Icons** — 6 стилей (thin/light/regular/bold/duotone/fill) в одной библиотеке.
- Или **Iconify** — доступ к 100+ наборам иконок через единый API.

Phosphor дает визуальную глубину за счет duotone-варианта — этого Lucide не умеет.

---

## Слой 5: Текстуры и эффекты

Вот чего реально не хватает для Dribbble-визуала:

| Эффект | Инструмент | Где применяется |
|---|---|---|
| Noise-текстура | CSS (SVG-фильтр) | Фон карточек, hero-секция |
| Glassmorphism | Tailwind `backdrop-blur` + `bg-white/10` | Navbar, модалки, мастера по шагам |
| Mesh-градиенты | CSS `radial-gradient` слои | Фон дашборда, лендинг |
| Grain-оверлей | SVG-фильтр `feTurbulence` | На всю страницу тонким слоем |
| Animated gradient borders | Magic UI `shimmer-border` | Активные карточки |
| Smooth scroll | **Lenis** | Общая плавность скролла |
| Reveal-анимации при скролле | **Framer Motion** + `useInView` | Все секции при появлении |

---

## Слой 6: Иллюстрации и графика

Dribbble-продукты отличаются наличием:

- **3D-иллюстрации** (Spline, Three.js) — для hero-секций.
- **Lottie-анимации** (lottie-react) — для пустых состояний, загрузок.
- **SVG-иллюстрации** — для onboarding, шагов мастера.

Lottie-анимация на ключевом шаге пользовательского сценария и Spline-сцена на главной — это будет "тот самый" момент.

---

## Итоговый рецепт

```text
Базовый стек (shadcn/ui + Radix + Tailwind 4 + Motion + Tremor)
  + Magic UI          (анимированные компоненты)
  + Phosphor Icons    (или Iconify)
  + Geist / Satoshi   (заголовочный шрифт)
  + Lenis             (smooth scroll)
  + lottie-react      (анимации пустых состояний)
  + SVG noise-текстура (CSS-фильтр, без зависимостей)
  + Spline            (опционально, для hero)
```

**Что дает наибольший эффект при минимальных усилиях** (по приоритету):

1. **Magic UI** — одна команда установки, максимум визуальной отдачи.
2. **Замена шрифта заголовков** — меняется одно CSS-правило, восприятие полностью другое.
3. **Noise + glassmorphism** — чистый CSS, 30 строк, добавляет "тактильности".
4. **Phosphor Icons** — замена Lucide, duotone-иконки дают глубину.
5. **Lenis + scroll-reveal** — общая "дороговизна" ощущения.

Остальное (Spline, Lottie) — вишенка на торте для финального полирования.
